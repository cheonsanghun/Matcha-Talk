Matcha-Talk 프로젝트 파일별 개요
================================

[백엔드 루트]
Matcha-Talk/backend/First_sql.sql - 전체 사용자/매칭/채팅/지원 테이블을 정의한 초기 MySQL 스키마 스크립트.
Matcha-Talk/backend/LICENSE - 프로젝트에 적용된 MIT 라이선스 전문.
Matcha-Talk/backend/build.gradle - Spring Boot 3 기반 백엔드의 의존성, 플러그인, JDK 버전을 정의.
Matcha-Talk/backend/gradle/wrapper/gradle-wrapper.jar - Gradle Wrapper 실행용 바이너리.
Matcha-Talk/backend/gradle/wrapper/gradle-wrapper.properties - Gradle 8.14.3 배포 URL 등을 지정한 Wrapper 설정.
Matcha-Talk/backend/gradlew - *nix 환경에서 Gradle Wrapper를 실행하는 스크립트.
Matcha-Talk/backend/gradlew.bat - Windows 환경에서 Gradle Wrapper를 실행하는 배치 파일.
Matcha-Talk/backend/settings.gradle - 루트 프로젝트명을 'project01'로 지정.

[백엔드 애플리케이션 엔트리]
Matcha-Talk/backend/src/main/java/net/datasa/project01/Project01Application.java - Spring Boot 시작점이며 스케줄링을 활성화.

[백엔드 설정]
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/JpaConfig.java - 엔티티/리포지토리 패키지 스캔과 트랜잭션 관리를 활성화.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/JwtAuthenticationFilter.java - 요청 헤더의 JWT를 검증해 SecurityContext에 인증 정보를 세팅하는 필터.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/SecurityConfig.java - JWT 기반 인증 설정, 예외 핸들러 등록, 무상태 세션, 허용 URL을 정의.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/WebConfig.java - 개발용 CORS 허용 도메인과 인증 공유 설정을 전역으로 지정.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/WebSocketConfig.java - /ws/chat 엔드포인트에 WebSocket 핸들러를 등록하고 핸드셰이크 인증/로그를 래핑.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/handler/RestAccessDeniedHandler.java - 인가 실패 시 403 JSON 응답을 반환하는 커스텀 핸들러.
Matcha-Talk/backend/src/main/java/net/datasa/project01/config/handler/RestAuthenticationEntryPoint.java - 인증 누락 시 401 JSON 응답을 반환하는 엔트리 포인트.

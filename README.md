# 🍃 Matcha-Talk 프로젝트
**Vue 3 + Spring Boot 기반 랜덤 채팅 웹앱**

## 🚀 빠른 시작

### 백엔드 실행
```bash
cd backend
./gradlew bootRun
```

### 프론트엔드 실행  
```bash
cd frontend
npm install
npm run dev
```

## ✅ 현재 완성 기능
- [x] 회원가입 + 이메일 인증
- [x] Spring Security + JWT 설정
- [x] Vuetify 3 UI 컴포넌트
- [x] API 연동 완료

## 🔧 기술 스택
- **Backend**: Spring Boot 3.3.2, JPA, MySQL, Spring Security
- **Frontend**: Vue 3, Vuetify 3, Vite, Axios, Pinia
- **Database**: MySQL 8.0+
- **Build**: Gradle, npm

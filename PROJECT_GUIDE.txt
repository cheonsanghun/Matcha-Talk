# 🍃 Matcha-Talk 프로젝트 개발 가이드

## 📋 프로젝트 개요
- **프로젝트명**: Matcha-Talk (랜덤 채팅 웹앱)
- **저장소**: https://github.com/cheonsanghun/Matcha-Talk
- **작업 브랜치**: `newtestbranch`
- **개발 시작**: 2024년 (재구성 프로젝트)
- **목표**: Vue3 + Spring Boot 기반 실시간 채팅 서비스

## 🛠 기술 스택
### 백엔드
- **Framework**: Spring Boot 3.3.2
- **언어**: Java 17
- **DB**: MySQL 8.0+
- **ORM**: JPA/Hibernate
- **보안**: Spring Security + JWT
- **빌드도구**: Gradle
- **패키지**: net.datasa.project01

### 프론트엔드  
- **Framework**: Vue 3 (Composition API)
- **UI**: Vuetify 3 (Material Design)
- **빌드**: Vite
- **HTTP**: Axios
- **상태관리**: Pinia
- **라우터**: Vue Router 4

### 개발 환경
- **백엔드 포트**: 8080
- **프론트엔드 포트**: 3000 (Vite dev server)
- **API Base URL**: http://localhost:8080/api

## ✅ 현재 완성된 기능

### 백엔드 완성 사항
1. **회원 관리 시스템**
   - User 엔티티 (완전한 회원정보 관리)
   - 로그인 실패 횟수 추적, 계정 잠금 기능
   - 이메일 인증 필수 정책

2. **이메일 인증 시스템**  
   - EmailVerification 엔티티
   - 다목적 인증 (회원가입/아이디찾기/비밀번호재설정)
   - 토큰 만료시간 관리

3. **REST API 엔드포인트**
   - POST `/api/users/signup` - 회원가입
   - GET `/api/users/exists?loginId=xxx` - 아이디 중복확인  
   - POST `/api/users/email/verify/request` - 이메일 인증번호 발송
   - POST `/api/users/email/verify/confirm` - 이메일 인증번호 확인
   - GET `/api/users/ping` - 헬스체크

4. **보안 설정**
   - Spring Security 설정 완료
   - JWT 토큰 기반 인증 준비
   - CORS 설정 완료
   - 비밀번호 BCrypt 해싱

### 프론트엔드 완성 사항
1. **회원가입 폼 (Register.vue)**
   - 완전한 실시간 입력 검증
   - 이메일 인증 플로우 구현
   - 아이디 중복확인 기능
   - 생년월일 선택기 (년/월/일 드롭다운)
   - 반응형 디자인 (Vuetify Material Design)

2. **API 연동**
   - Axios 인스턴스 설정 완료
   - JWT 토큰 자동 헤더 추가
   - 환경변수 기반 API URL 설정

3. **기본 페이지 구조**
   - Home, Login, Register 페이지
   - Chat, VideoChat 페이지 (UI만)
   - MatchingSetup, MatchingResult 페이지 (UI만)
   - Profile 페이지 (기본 구조)

## 💡 개발 시 참고사항

### API 응답 형식
```json
// 성공 응답
{
  "userPid": 1,
  "loginId": "testuser",
  "nickName": "테스트",
  "email": "test@gmail.com",
  "emailVerified": true
}

// 에러 응답  
{
  "message": "이미 사용 중인 아이디입니다.",
  "timestamp": "2024-01-15T10:30:00"
}
```

### 중요한 비즈니스 규칙
1. **이메일 인증 필수**: 인증 완료 전까지 로그인 불가
2. **Gmail만 허용**: 이메일 주소 정규식 검증
3. **비밀번호 규칙**: 8자 이상, 소문자+숫자+특수문자 각 1개 이상
4. **계정 잠금**: 로그인 5회 실패시 일정시간 잠금
5. **JWT 토큰**: 24시간 유효기간

### 환경변수 설정
```bash
# .env.development (프론트엔드)
VITE_API_BASE_URL=http://localhost:8080/api

# application-dev.properties (백엔드)  
spring.datasource.url=jdbc:mysql://localhost:3306/matcha_talk
spring.mail.host=smtp.gmail.com
```

## 🐛 알려진 이슈 및 해결방법

### 이슈 1: CORS 에러
- **증상**: 브라우저에서 API 호출 시 CORS 에러

### 이슈 2: 이메일 발송 실패
- **증상**: 이메일 인증번호 전송 안됨
- **해결**: Gmail SMTP 설정 및 앱 비밀번호 확인

### 이슈 3: JWT 토큰 만료
- **증상**: 로그인 후 일정시간 후 API 호출 실패  
- **해결**: 토큰 리프레시 로직 구현 예정
